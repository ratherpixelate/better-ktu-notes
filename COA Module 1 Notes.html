Functional units of a computer

DrawDefine

ComputerAn electronic calculating machine that accepts input, processes it according to a list of internally stored instructions, and produces output.

Input unit

Takes binary information from input devices, converts it to the format the computer expects, and passes it to memory or the processor.

Memory unit

Stores instructions and data as bits. Processor reads instructions and reads/writes data during program execution.

ALU

Executes arithmetic (add, subtract) and logic (compare) operations. Operands sit in general purpose registers, which are faster than cache. Results go back to memory or stay in a register for immediate use.

Output unit

Takes processed results in binary form and converts them into a form the output device understands.

Control unit

Coordinates input, memory, ALU and output. Instructions decide what happens (transfer, process). The control unit's timing signals decide when.

Instructions and data

  • Instructions command the machine to: move information inside the computer (memory to ALU), move it between the computer and I/O devices, or do arithmetic and logic. A sequence of instructions for a task is a program, stored in memory. The processor fetches and executes it.
  • Data are the operands instructions work on: numbers or encoded characters, all stored as strings of bits.

Memory unit in detail

  • Fetching one bit at a time is impractical, so memory moves a group of bits at once: a word. The number of bits in it is the word length. Each word location has an address.
  • RAM: any location is reached in a short, fixed time that does not depend on the location. That time is the memory access time.
  • To cut communication time, a small fast RAM called cache sits tightly coupled to the processor. Main memory is larger and slower.
  • Primary storage = RAM (cache + main memory). It is expensive to enlarge, so bulk data goes on secondary storage (magnetic disks and tapes, optical disks): slower, but infrequently used data can live there.
  • Cost depends on access time: shorter access time means higher cost.

Registers (in processor)FastestSmallestHighest

AddedYour notes ask "why is cache access time less than main memory?" and never answer. Cache is small and built from faster memory cells, and it sits on or next to the processor chip, so signals travel a short distance and need no slow bus transfer. Main memory is much larger, built from slower, cheaper cells, and reached over the bus.

Registers are the fastest storage in the machine and hold data temporarily.

Fetch and execute, step by step

  1. MAR ← [PC]. PC contents go to MAR, which puts the address on the address bus and selects a memory location.
  2. Control unit issues a READ signal. The instruction comes over the data bus into MDR.
  3. IR ← [MDR].
  4. The instruction in IR is decoded so the processor knows the operation.
  5. PC ← [PC] + 4 so it points to the next instruction.
  6. If the operand is in a register, the ALU operates on it directly.
  7. If the operand is in memory: MAR ← address of operand, issue READ, operand arrives in MDR, then goes to the ALU (directly, or via a register).
  8. The result goes to a register, to memory (address in MAR, data in MDR, WRITE signal) or to an output device.
  9. Normal execution can be pre-empted by an interrupt at any point.

Interrupts

DefineList classes

InterruptA request that breaks normal program execution because a device needs urgent servicing.

Procedure

  1. The device raises an interrupt signal.
  2. The processor saves its state first: PC, general registers and some control information go to memory.
  3. It executes the matching interrupt-service routine (ISR).
  4. When the ISR finishes, the state is restored and the interrupted program continues.

Bus structures

BusA group of parallel wires that connects several devices. Each wire carries one bit.

Single-bus structure

Simplest interconnect, but only one transfer happens at a time. The devices differ widely in speed: printer and keyboard are slow, optical disks fast, and memory and processor are the fastest parts of the computer.

Fixes for the speed mismatch

  • Add buffer registers to devices to hold information during transfers.
  • Use a two-bus structure (below).

Two-bus structure

  • I/O transfers stay under the processor's direct control: it starts the transfer and monitors progress until completion.
  • Advantage: good operating speed. Disadvantage: higher cost.
  • A high-performance bus, a low-performance bus and a bridge between them.

System software

Short note

The computer must already hold some system software before a user can enter and run a program. System software is a collection of programs run as needed to:

  • receive and interpret user commands,
  • run standard application programs (word processors, games),
  • manage storage and retrieval of files on secondary storage,
  • control I/O units to take input and produce output,
  • translate source programs into object form (machine instructions),
  • link and run user programs with standard library routines (numerical packages).

In short, system software coordinates all activity in the computing system.

Memory locations and addresses

NumericalDefineFixed
  • Memory is millions of cells, each holding one bit. Bits are handled in fixed-size groups: a group of m bits stored or retrieved in one basic operation is a word, and m is the word length (typically 16 to 64 bits).
  • A 32-bit word can hold one 32-bit 2's-complement number, or four 8-bit ASCII characters.
  • A byte is always 8 bits.

Address space

k-bit address → addresses 0 … 2^k − 1 → address space = 2^k locations
  • 24-bit address: 224 = 16,777,216 locations = 16M.
  • 32-bit address: 232 = 4G locations. With byte addressing, that is 4 GB.
  • Locations needed → bits needed: 64M words = 226, so 26 address bits.

AddedThe last two bullets are worked examples I added. The 24-bit one is from your notes.

Byte addressability

Successive addresses refer to successive bytes. For a 32-bit word, consecutive words sit at addresses 0, 4, 8, 12 and so on. This is why PC increases by 4 after each instruction.

Big-endian and little-endian

Two ways of storing a multi-byte value (int, float). Take 0x12345678 stored at address 1000:

  • Big-endian: most significant byte at the lowest address.
  • Little-endian: least significant byte at the lowest address.

Alignment

Words are aligned to multiples of their size: a 4-byte word starts at an address divisible by 4.

Memory operations

  • Load (fetch / read): copies the contents of a memory location to the CPU. The word in memory is unchanged. CPU sends the address and requests a read, memory returns the data.
  • Store (write): copies a word from the CPU into a memory location, destroying the old contents. CPU sends the address and the data.

Properties to remember

  • Sign-magnitude: low bits are the magnitude. Two zeros.
  • 1's complement: subtraction becomes addition of the 1's complement, but addition needs an end-around carry. Still two zeros, which causes problems.
  • 2's complement: one zero, no end-around carry. It is the 1's complement shifted one position.

AddedWorked examples for the exam (4-bit).

1's complement, 5 + (−2): 0101 + 1101 = 1 0010. Add the end-around carry: 0010 + 1 = 0011 = +3.

Instruction types and formats

NumericalWrite programsAdded

A computer needs instructions for four kinds of operation:

  1. Data transfer between main memory and CPU registers.
  2. Arithmetic and logic operations on data (ADD, SUB, MUL, DIV, AND, OR, XOR, shifts).
  3. Program sequencing and control (branch, jump).
  4. I/O transfers.

Notation

  • Register Transfer Notation (RTN): memory locations are named LOC, A, VAR2 and registers R0, R5. Contents are written in square brackets. R1 ← [LOC] copies memory location LOC into R1. R3 ← [R1] + [R2] adds two registers into R3.
  • Assembly notation: Move LOC, R1 and Add R1, R2, R3.

Using CPU registers instead of the accumulator

With several general purpose registers, Move A,Ri, Move Ri,A and Add A,Ri generalise Load, Store and Add (Ri plays the accumulator). Many instructions then involve only registers: Add Ri,Rj (Rj is source and destination) or Add Ri,Rj,Rk (Ri, Rj sources, Rk destination).

Advantages of registers

  • Access is faster than main memory, because registers are inside the processor.
  • Few bits name a register: 5 bits are enough for 32 registers.
  • Instructions containing only register names normally fit in one memory word.

Instruction sequencing and branching

ExplainWrite programs

Straight-line sequencing

The CPU fetches and executes instructions one at a time in increasing address order. To start, the address of the first instruction goes into PC. Executing one instruction has two phases:

  • Instruction fetch: the instruction at the address in PC is read into IR.
  • Instruction execute: IR is examined, then the operation runs. That may mean fetching operands from memory or registers, doing the arithmetic or logic, and storing the result.
  • At some point PC advances by 4 to point to the next instruction. When execution finishes, the next fetch begins.
Program for C ← [A] + [B], two-address machine, 32-bit instructions

address i     Move A, R0
address i+4   Add  B, R0
address i+8   Move R0, C

Branching

To add n numbers you don't write n separate Add instructions. You put one Add in a loop, which executes the same straight-line sequence repeatedly. A branch instruction loads a new value into PC, so the processor continues from that address. A conditional branch only does so if its condition holds. Otherwise PC advances normally.

        Move  N, R1          ; R1 = counter, loaded with n
        Clear R0             ; running sum
LOOP    Determine address of "Next" number and Add "Next" to R0
        Decrement R1         ; R1 ← [R1] − 1
        Branch>0 LOOP        ; repeat while result of decrement > 0
        Move  R0, SUM        ; store the total

Condition code flags

The processor records facts about the last result in single bits, grouped in the condition code register (status register), for later conditional branches.

FlagNameSet to 1 when
NNegativeResult is negative
ZZeroResult is zero
VOverflowArithmetic overflow occurs
CCarryA carry-out results from the operation

Otherwise each flag is cleared to 0. Branch>0 in the loop above tests N and Z: it branches only when the result is neither negative nor zero.

Details worth writing in answers

  • Indirect via memory Add (A),R0: CPU reads location A, finds value B. B is the operand's address, not the operand. A second read fetches the operand from B, then it is added to R0. With a register, Add (R1),R0, R1 holds B directly, saving one memory read.
  • Index, two uses. Offset as a constant, 20(R1): R1 holds a base address, X=20 is the displacement. Offset in the register, 1000(R1): X=1000 is the array's base address and R1 holds the element offset. Any general purpose register can act as the index register.
  • Relative: the target is X bytes from where PC points. It is the usual mode for branch targets, and it can also reach data operands.
  • Autoincrement removes the separate increment instruction when stepping through a list.

Instruction set architecture principles

DefineClassifyAdded

ISAThe set of instructions a processor can understand and execute. It is the interface between hardware and software, defines what the processor can do, and matters to both hardware designers and software developers.

Topics under ISA: classification, memory addressing, addressing modes, type and size of operands, operations, control flow, encoding.

Classification

  • By instruction complexity: CISC (Complex Instruction Set Computer) and RISC (Reduced Instruction Set Computer).
  • By where operands live: stack-based (Java Virtual Machine), accumulator-based (early computers), register-based. Register-based splits into register-memory (x86) and load-store (MIPS, RISC-V, ARM).

Operations

Arithmetic and logical (ADD, SUB, MUL, DIV, AND, OR, XOR, shifts), data transfer, program control (branch, jump), and I/O (read, write system calls). Nearly every computer provides the first three groups in full. Support for system functions varies widely.

Control-flow instructions

Four kinds of control-flow change: conditional branches, jumps, procedure calls, returns.

  • Branches mostly use PC-relative addressing.
  • Returns and indirect jumps have a target that isn't known at compile time, so they use register-indirect addressing.

RISC architecture

ExplainShort noteAdded

Core principles

  • Simple, fixed-length instructions, e.g. 32 bits, which makes pipelining easy.
  • Load-store architecture: only LOAD and STORE touch memory. Everything else works on registers.
  • Limited addressing modes: immediate, register, displacement.
  • Large register set: 32 or more general purpose registers (GPRs), which cuts memory traffic.
  • Hardwired control unit, which executes faster. CISC uses microcode (microprogrammed control) as well.

Data types and registers

  • Integers: 8-bit bytes, 16-bit half words, 32-bit words, 64-bit double words.
  • Floating point: 32-bit single and 64-bit double precision.
  • Registers: 32 GPRs (MIPS $0 to $31) and 32 floating-point registers F0 to F31, each holding a 32-bit single or a 64-bit double value.
  • Zero register: hardwired to 0, used for base addressing.

Benefits of RISC

  • Pipelining efficiency: fixed-length instructions simplify fetch and decode.
  • Higher clock rates: fewer complex instructions mean shorter cycles.
  • Compiler friendly: easy for a compiler to optimise.
  • Scalability: modular design, e.g. RISC-V extensions.

One-page cheat sheet

AddedRevise the night before

Number ranges (n bits)

  • Unsigned: 0 to 2n−1
  • Sign-mag, 1's comp: ±(2n−1−1), two zeros
  • 2's comp: −2n−1 to 2n−1−1, one zero
  • −x in 2's comp = invert + 1

Addresses

  • k bits → 2k locations
  • Byte addressable, 32-bit words: PC += 4
  • Data bus width = word length
  • Load leaves memory unchanged, Store overwrites

Fetch cycle

  • MAR ← [PC]
  • READ, MDR ← M[MAR]
  • IR ← [MDR], decode
  • PC ← [PC] + 4

Effective address

  • Indirect: EA = [Ri] or [A]
  • Index: EA = X + [Ri]
  • Relative: EA = X + [PC]
  • Auto+: EA = [Ri], then Ri++
  • Auto−: Ri−−, then EA = [Ri]

Flags

  • N negative, Z zero
  • V overflow, C carry-out
  • Overflow: same-sign operands, opposite-sign result

Endianness

  • Big: MSB at lowest address
  • Little: LSB at lowest address

Instruction length

  • 3-addr: 3k + opcode
  • 2-addr: 2k + opcode
  • 1-addr: k + opcode
  • 0-addr: opcode only (stack)
  • n opcode bits → 2n instructions

RISC in one line

  • Fixed 32-bit, load-store, 32+ registers, few modes, hardwired control, pipelines well
  • CISC: variable length, memory operands, many modes, microcode

IEEE 754

  • Single: 1 + 8 + 23, bias 127
  • Double: 1 + 11 + 52, bias 1023
  • value = (−1)s × 1.f × 2E−bias

1. The Five Functional Units of a Computer

A digital computer consists of five functionally distinct components: Input Unit, Memory Unit, Arithmetic and Logic Unit (ALU), Output Unit, and Control Unit. The ALU and the Control Unit together constitute the Central Processing Unit (CPU).

Syllabus Scope Note

Standard textbooks (Hamacher Ch. 1) begin with historical evolutions of vacuum tubes and transistors. These are not in your university syllabus. Focus entirely on the interconnections, bus signals, and register operations.

2. Data Representation & IEEE 754 Floating Point

University question papers regularly set numerical conversions for 3 to 5 marks. The IEEE 754 standard specifies single-precision (32-bit) and double-precision (64-bit) representations:

IEEE 754 Single Precision Format (32-Bit) High-Yield Numerical
Value = (-1)S × (1.M) × 2(E - 127)

Field Breakdown: 1 Sign Bit (S) · 8 Exponent Bits (E, Excess-127 biased) · 23 Fraction / Mantissa Bits (M, with implicit leading 1).

3. Architectural Contrast: RISC vs. CISC

A frequent 10-mark essay choice in university examinations. Answers must tabulate distinct architectural properties rather than general descriptions:

Criterion RISC (Reduced Instruction Set) CISC (Complex Instruction Set)
Instruction Size Fixed 32-bit length; uniform decoding Variable length (1 byte to 15 bytes)
Memory Access Load/Store only; operands must reside in registers Memory operands allowed directly in arithmetic instructions
Addressing Modes Few simple modes (Register, Immediate, Base-offset) Many complex, multi-level memory addressing modes
Control Implementation Hardwired control logic for single-cycle execution Microprogrammed ROM control store
Register File Large general-purpose register file (32+ registers) Small specialized register file (e.g., accumulator, index)
Examiner's Grading Blueprint

When answering this question: (1) state the architectural philosophy, (2) provide the 5-point comparison table above, and (3) cite two real-world processor examples (e.g. ARM/MIPS for RISC; Intel x86 for CISC) to earn full marks.

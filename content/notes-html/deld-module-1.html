Module 1: Introduction to Digital Systems and Verilog

Digital abstraction

DefineLikely exam

Digital abstractionTreating a continuous analog signal (a voltage) as one of two discrete logic values, 0 and 1. A voltage below a threshold is read as logic 0, above a threshold as logic 1, and the region in between is not used.

  • It lets you design with Boolean algebra and logic gates and ignore the physical details of each voltage.
  • Circuits are reliable even with noise: a small disturbance does not change a 0 into a 1 as long as the voltage stays in its allowed range.
  • Designs stay simple, and the same logic can be built in different technologies (TTL, CMOS).

AddedWhy digital beats analog for computation: values can be copied, stored and regenerated without accumulating error, and the same hardware can be reused. An analog signal changes a little with every stage, a digital one is restored to a clean 0 or 1 by each gate.

  • Each position has a weight that is a power of the base. Position values to the left of the point are b0, b1, … and to the right b-1, b-2, ….
  • Binary to hex: group bits in 4s from the point outwards. Binary to octal: group in 3s. Pad with zeros at the ends of the groups.
  • Hex to binary: replace each hex digit with 4 bits. Octal to binary: replace each digit with 3 bits.
  • Binary to decimal: add the weights of the 1 bits.
  • Decimal to binary (integer part): divide by 2 repeatedly and read the remainders from last to first. Fraction part: multiply by 2 repeatedly and read the integer parts from first to last.

ShortcutTo read a negative 2's complement number: invert and add 1 to get the magnitude. Example: 1001 inverts to 0110, plus 1 is 0111, so 1001 = −7. The most negative value (1000 in 4 bits = −8) has no positive partner.

1's complement subtraction (A − B)

  1. Take the 1's complement of B (invert all bits of B).
  2. Add it to A.
  3. Final carry out of the MSB: the result is positive. Add the carry back to the sum (end-around carry). That is the answer.
  4. No final carry: the result is negative and is in 1's complement form. Invert it to get the magnitude, and write a minus sign.

2's complement subtraction (A − B)

  1. Take the 2's complement of B (invert and add 1).
  2. Add it to A.
  3. Final carry: the result is positive. Discard the carry. The rest is the answer.
  4. No final carry: the result is negative and is in 2's complement form. Take the 2's complement of the sum to get the magnitude.

AddedOverflow (not in the class notes): when two numbers of the same sign are added and the result has the opposite sign, it does not fit. Rule for 2's complement: overflow if the carry into the MSB differs from the carry out of it. Example, 4 bits: 0101 + 0100 (5 + 4) = 1001, which reads as −7, so overflow. Also (−5) + (−4) = 0111, which reads as +7, so overflow. Adding numbers of opposite signs can never overflow.

Fixed-point numbers

DefineNumericalAdded

AddedThe syllabus lists fixed-point numbers but the class notes have nothing on them. Standard treatment:

Fixed-point numberA binary number with the binary point at a fixed position. In Qm.n format there are m integer bits and n fraction bits. The stored integer is the value × 2n, so value = stored integer ÷ 2n.

  • Resolution (smallest step) = 2−n. For Q4.4 (8 bits) that is 0.0625.
  • Unsigned Q4.4 range: 0 to 15.9375 (255 ÷ 16). Signed (2's complement) Q4.4 range: −8 to 7.9375.
  • Addition and subtraction work exactly like integers, as long as both numbers use the same format.
  • Multiplication: multiply the stored integers (Qm.n × Qm.n gives 2n fraction bits), then shift right by n to go back to Qm.n.
Example (Q4.4)WorkingStored bits
6.756.75 × 16 = 10801101100
−2.5 (2's complement)−2.5 × 16 = −40, 8-bit 2's complement11011000
1.5 × 2.2524 × 36 = 864, shift right 4 gives 54, 54 ÷ 1600110110 = 3.375

  • Advantage: fast and cheap hardware, no exponent logic. Disadvantage: limited range and fixed resolution, so very large or very small values do not fit.

Floating-point numbers

DefineNumericalDrawLikely exam

Floating pointA number stored as sign, exponent and mantissa, so the point "floats". Value = (−1)s × 1.mantissa × 2(exponent − bias). It gives a huge range at the cost of rounding.

IEEE 754 single precision (32 bits)

1sign (bit 31)
8biased exponent (bits 30 to 23)
23mantissa, fraction after the leading 1 (bits 22 to 0)
  • Bias = 127. Stored exponent = 127 + actual exponent.
  • Sign bit: 1 for negative, 0 for positive.
  • Normalisation: shift the point so there is a single 1 before it, 1.xxxx. Shifting left by k gives × 2−k, shifting right by k gives × 2k. The leading 1 is not stored (hidden bit).

Normalisation examples (from the class notes, checked)110.011 = 1.10011 × 22. 101010111.0101011 = 1.010101110101011 × 28.

Logic levels, DC specifications and noise margins

DefineNumericalDrawLikely exam

Digital circuit operationLogic levels are voltage ranges, not exact voltages. Every logic family (TTL, CMOS, …) specifies input DC specifications, output DC specifications and noise margins so that switching is reliable.

SymbolMeaningTTL typical
VIH(min)Minimum input voltage guaranteed to be read as logic 12.0 V
VIL(max)Maximum input voltage guaranteed to be read as logic 00.8 V
VOH(min)Minimum output voltage a gate produces for a HIGH output2.4 V
VOL(max)Maximum output voltage a gate produces for a LOW output0.4 V
NMH = VOH(min) − VIH(min) = 2.4 − 2.0 = 0.4 V
NML = VIL(max) − VOL(max) = 0.8 − 0.4 = 0.4 V
  • Noise margin is the amount of noise a signal can pick up and still be read correctly. Larger is better.
  • Always VOL < VIL < VIH < VOH. Between VIL and VIH the input is undefined and the output may be wrong or unstable.

NumericalTTL gate: VOH = 2.4 V, VIH = 2.0 V, VIL = 0.8 V, VOL = 0.4 V. NMH = 0.4 V, NML = 0.4 V. These are the typical values from the class notes, and they are not guaranteed for every device, so use the datasheet in an exam if values are given.

Power supplies

AddedThe syllabus lists power supplies but the class notes do not cover them. Standard points:

  • A logic IC has a supply pin (VCC for TTL, VDD for CMOS) and a ground pin (GND). Classic TTL runs on +5 V. CMOS families run on 5 V, 3.3 V and lower (for example 1.8 V).
  • Logic levels are defined relative to the supply, so the input and output specifications change with the supply voltage. Parts on different supplies need level translation.
  • Supply current ICC is drawn from VCC and returns through GND. Power = VCC × ICC.
  • Decoupling: a small capacitor close to each IC supplies the sudden current spikes when gates switch and keeps the supply steady.

Driving loads

DefineNumericalDrawLikely exam
  • IOH: current an output gives when it is HIGH. The gate sources current out of the pin. Datasheets show it as negative because current flows out of the pin.
  • IOL: current the output takes when it is LOW. The gate sinks current into the pin. Shown as positive.
  • IIH and IIL: input currents each gate input draws when HIGH or LOW.

Driving other gates: fan-out

Fan-out (HIGH) = |IOH(max)| ÷ IIH
Fan-out (LOW) = IOL(max) ÷ |IIL|
Fan-out = the smaller of the two

Numerical (illustrative values)IOH = 0.4 mA, IIH = 20 µA gives 20 inputs HIGH. IOL = 8 mA, IIL = 0.4 mA gives 20 inputs LOW. Fan-out = 20. These numbers are typical for a low-power Schottky TTL family and are used only as an example. Use the values given in the question.

Resistive loads

  • Output HIGH, load resistor to ground: I = VOH ÷ R must not exceed |IOH(max)|, so Rmin = VOH(min) ÷ |IOH(max)|. With VOH = 2.4 V and IOH = 0.4 mA: Rmin = 6 kΩ.
  • Output LOW, load resistor to VCC: I = (VCC − VOL) ÷ R must not exceed IOL(max), so Rmin = (VCC − VOL(max)) ÷ IOL(max). With VCC = 5 V, VOL = 0.4 V, IOL = 8 mA: Rmin = 575 Ω.

CheckThe class notes write the LOW-output formula as Rmin ≥ VOL(max) ÷ IOL(max). That gives the resistance for a load that sees only VOL across it, and it is not the usual case. As far as I know, for a resistor connected to VCC the voltage across it is VCC − VOL, so use the form above. If your teacher uses the notes' form, follow that for marks.

Driving LEDs

  • Output HIGH (current out of the pin): I = (VOH − Vf) ÷ R, and I ≤ |IOH(max)|.
  • Output LOW (current into the pin): I = (VCC − Vf − VOL) ÷ R, and I ≤ IOL(max), so R ≥ (VCC − Vf − VOL) ÷ IOL(max).

Numerical (illustrative values)VCC = 5 V, LED drop Vf = 2 V, VOL = 0.4 V, IOL(max) = 16 mA. Rmin = (5 − 2 − 0.4) ÷ 16 mA = 162.5 Ω. A 180 Ω resistor gives I = 2.6 ÷ 180 = 14.4 mA, which is safe. A 330 Ω resistor gives 7.9 mA.

How to analyse a driver circuit

  1. Identify the output level (HIGH or LOW).
  2. Trace the current direction: HIGH means current leaves the pin (use IOH), LOW means current enters the pin (use IOL).
  3. Apply Ohm's law to the load to find the actual current.
  4. Compare with the IOH or IOL rating. If the actual current is larger, the output cannot drive the load safely.

Current through the VCC and GND pins

  • Output HIGH: the pin sources current, so it comes from VCC. Output LOW: the pin sinks current, so it goes to GND.
  • Class-note example: internal current IR = 1 mA, load current 10 mA. Output HIGH: ICC = 1 + 10 = 11 mA, IGND = 1 mA. Output LOW: ICC = 1 mA, IGND = 1 + 10 = 11 mA.

CheckThe circuit figure for this example is hard to read in the class notes. I read it as one gate with 1 mA internal current and a 10 mA load, and worked out both cases above. If your question has a different figure, use the same rule: the load current flows through VCC when the output is HIGH and through GND when it is LOW.

HDL abstraction and the design flow

DefineDrawDifferentiateLikely exam

HDLA hardware description language (Verilog, VHDL) describes digital hardware in text. It describes concurrent hardware, not a sequence of instructions, and it can be simulated and then synthesised into gates.

Abstraction levelDescribesVerilog example
BehaviouralWhat the hardware does (function). Uses always blocks.always @(*) Y = A + B; (combinational block that re-evaluates whenever any input changes)
RTL (register transfer level)How data moves between registers and what happens at each clockalways @(posedge clk) Q <= D; (D flip-flop: on the rising clock edge, non-blocking assignment loads D into register Q)
StructuralActual gates and connections, like a netlistand g1 (o, a, b); (built-in AND primitive, instance g1, output o, inputs a and b)
  • Abstraction lets designers write high-level code and let tools generate the gate-level design.

Modern digital design flow

StepWhat happens
1. SpecificationDefine what the circuit must do: truth tables, equations, functionality.
2. RTL coding in VerilogWrite HDL code that describes the behaviour.
3. SynthesisA tool converts RTL into a gate-level netlist using logic gates.
4. Place and routeMaps the gate-level design onto silicon or onto the FPGA fabric.
5. Fabrication / programmingASIC: fabricate the chip. FPGA: generate the bitstream and program the device.

AddedSimulation is part of every real flow: write a testbench, apply inputs, and check the outputs before synthesis. The class notes list five steps and leave simulation out, so mention it as a step between 2 and 3 if the question asks for a complete flow.

The module

ModuleThe basic hardware unit in Verilog: a component with input and output ports, internal wires and logic.

module <name> (port_list);
    declarations;
    statements;
endmodule

module inverter (input A, output Y);

  • input A: A is an input pin. output Y: Y is an output pin. assign Y = ~A; drives Y continuously with NOT of A.

Grouping

  • Resolution 2^−n

Gates

  • AND: all 1. OR: any 1
  • NAND: not all 1. NOR: all 0
  • XOR: inputs differ. XNOR: same
  • NAND and NOR are universal

Levels (TTL)

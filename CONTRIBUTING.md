# Contributing to BetterKTUNotes

Thank you for helping improve syllabus notes for KTU Semester 3!

## How You Can Contribute

1. **Reporting Errors**: If you find an OCR error, formula typo, or missing syllabus line, please open an Issue.
2. **Drafting Upcoming Modules**: Notes for COA Module 3/4, DS Module 2/3/4, and DBMS Module 2/3/4 are currently in drafting. Pull requests with syllabus-aligned sections are welcome.
3. **Format Guidelines**:
   - Keep notes syllabus-aligned without textbook filler.
   - Use standard clear ASCII/SVG block diagrams where applicable.
   - Mark University PYQs and important definitions clearly.

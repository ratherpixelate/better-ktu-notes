Functional Units of a Computer & Basic Operational Concepts

A modern digital computer consists of five functionally independent main parts: Input, Memory, Arithmetic & Logic Unit (ALU), Output, and Control Unit. The ALU and Control Unit combined are collectively known as the Central Processing Unit (CPU).

IEEE 754 Floating Point Formula (Single Precision 32-bit)

Any normalized real binary number is stored across 3 fields (1 sign bit, 8 exponent bits, 23 mantissa bits):

Value = (-1)S × (1.M) × 2(E - 127)

Where S = 0 for positive, S = 1 for negative. Bias is fixed at 127 for single precision and 1023 for double precision.

2. Key Comparison: RISC vs. CISC Architecture

When answering a 7-mark or 10-mark comparison question, tabulate at least five structural contrasts:

Parameter RISC (Reduced Instruction Set) CISC (Complex Instruction Set)
Instruction Length Fixed length (typically 32-bit words). Variable length (1 byte to 15 bytes).
Execution Model Load-Store architecture (only Load/Store touch memory). Memory-to-Memory or Register-to-Memory operations.
Addressing Modes Few, simple modes (Register, Immediate, Indirect). Many complex, multi-level addressing modes.
Control Unit Type Hardwired control unit (faster, pipelined). Microprogrammed control store (ROM based).
Register Set Large register file (typically 32 or more general regs). Small specialized register file (e.g. x86 EAX, EBX).
